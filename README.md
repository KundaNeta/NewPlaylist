# Calculator App

A modern, responsive calculator application built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and intuitive user interface
- Keyboard support for faster input
- Responsive design that works on all devices
- Division by zero protection
- Number formatting with thousand separators

## Usage

### Opening the Calculator

Simply open the `index.html` file in your web browser.

### Using the Calculator

**Mouse/Touch Input:**
- Click number buttons (0-9) to enter numbers
- Click operator buttons (+, -, ×, ÷) to perform operations
- Click = to calculate the result
- Click AC (All Clear) to reset the calculator
- Click DEL to delete the last digit
- Click . to add a decimal point

**Keyboard Input:**
- Number keys (0-9) - Enter numbers
- `+`, `-`, `*`, `/` - Arithmetic operators
- `Enter` or `=` - Calculate result
- `Backspace` - Delete last digit
- `Escape` - Clear all
- `.` - Decimal point

## Features Explained

- **Display**: Shows the current number and previous operation
- **Number Formatting**: Large numbers are formatted with commas for readability
- **Decimal Support**: Full support for decimal numbers
- **Error Handling**: Prevents division by zero with an alert
- **Chain Calculations**: Can perform multiple operations in sequence
